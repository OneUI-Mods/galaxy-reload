# GUIとコマンドからSystemUIを再読み込み

「再読み込み」タブからSystemUIを読み込み直せるようになりました。画面がONで解除済みであることを確認し、その状態をAdaptive Barへ一度だけ引き継ぎます。認証設定は変更しません。消灯や強制認証が発生した場合は引き継ぎを中止します。

「コマンド」タブからコマンドを準備すると、rootでcheckによる状態確認とreloadによる再読み込みを実行できます。アプリを更新してもコマンドは引き続き使えます。

Galaxy S26 Ultra（SM-S948Q）のAndroid 16 / AZHL、Android 17 / BZI9向けです。root、API 102対応Vector、Adaptive Bar 0.6.18以降が必要です。初回や引き継ぎに失敗した場合は手動で解除してください。

準備版を利用中の方は、署名済みrelease APKを上書きしてください。許可済みのSU権限は引き継がれます。
